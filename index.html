My principles

I approach every project with three main principles which helped me develop quality applications:

  • Understanding before abstracting: Designing and understanding the application before writing code is critical for reliable software
  • Follow good practice: Composing clean, maintainable code and documentation is essential for long-term software support
  • Never stop learning: Technology is changing fast and constant adaptation is important to keep up with it

When facing a new project or problem I...

  1. identify the problem and determine the goal
  2. discover the most fitting software architecture depending on factors at place
  3. split the work into multiple technical steps which can be solved feature by feature

While doing so, it becomes important to watch out for code readability, debug individual features and test the application even for rare edge cases to ensure reliability and best performance in production.
